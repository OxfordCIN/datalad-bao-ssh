Command line reference
======================

.. toctree::
   :maxdepth: 1

   Run this command to setup your SSH environment to create and
   use short-lived SSH certificates for authentication to your Datalad
   remotes.

   Option arguments:

   * `--update-bao` When provided the latest version of the 'bao' tool will
   be downloaded and installed if it is newer than the version installed in
   your home folder. For system-wide 'bao' installations this does nothing.
